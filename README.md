## Featured Projects

### 🚨 [Incident Intelligence Platform](https://github.com/vxanonymous/incident-platform)
**TypeScript · AWS Lambda · DynamoDB · SQS · React · AWS CDK**

Serverless incident-management platform that ingests raw alerts, deduplicates and correlates them into actionable incidents, and uses LLMs to auto-triage severity and recommend remediation. Ships multi-tenant authentication with RBAC, rate limiting, and HMAC-signed pagination, plus a dependency-injection container enabling dual-mode operation across AWS services and local SQLite. Backed by **1,000+ tests** across unit, integration, and end-to-end layers, with all infrastructure defined as code in AWS CDK (Lambda, DynamoDB, SQS, and CloudWatch dashboards).

### 🧭 [Vacation Planning System](https://github.com/vxanonymous/vp-chatbot) · [Live](https://vp-chatbot.surge.sh)
**Python · FastAPI · React · MongoDB · Redis · Docker**

Full-stack, AI-driven system for planning personalized vacations through conversation, with intelligent destination recommendations, interactive map visualization, and real-time conversational assistance. The React frontend uses custom hooks, Context API, and the MapTiler SDK against **15+ REST endpoints**, while an async FastAPI backend follows Domain-Driven Design with **10+ service modules** for auth, destination extraction, conversation management, and request deduplication. Containerized with Docker Compose and Redis caching, at **93% test coverage** (pytest and vitest).
